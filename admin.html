Facebook Automation Webhook

Automatically post to Facebook via Make.com or Zapier when you publish.

How to set this up:
1. Go to Make.com (or Zapier) and create a new scenario.
2. Add a Webhooks → Custom Webhook trigger — copy its URL.
3. Add a Facebook Pages → Create a Post action, mapping {{title}} and {{postUrl}} from the webhook payload.
4. Paste the webhook URL below and click Save. Every "Publish" will fire it automatically.

Stored locally in this browser. Paste it again if you use a different device.

Payload Preview

When you click Publish, this JSON is sent to your webhook:

{
  "title":       "Your post title",
  "category":    "News | Testimony | Article",
  "description": "Post body text…",
  "imageUrl":    "https://storage.googleapis.com/…",
  "postId":      "Firestore document ID",
  "postUrl":     "https://geezhospital.com/news.html#postId"
}
